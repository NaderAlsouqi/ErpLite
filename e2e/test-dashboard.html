Real bugs the suite found

4 application defects · with code-level evidence
Highbackend · SQL

Virtual refunds → HTTP 500

Three VirtualInvoice refund endpoints fail with Invalid object name 'Virtual_srf' — a required table/view is missing from tenant SC_ERP78. Breaks 4 virtual-refund pages.

Mediumfrontend · Angular

List pages crash on null data

12 invoice / refund / transfer list pages call .map() on a null API response → TypeError caught by the global handler. Needs a (data ?? []) null-guard.

Mediumbackend · Dapper

Stamps update/delete → 404 on success

SP_UpdateSignature/SP_DeleteSignature use SET NOCOUNT ON, so Dapper returns −1; the repo gates on rows > 0 and returns NotFound() even though the row was changed.

Lowfrontend · UX

Journal voucher swallows failed save

The account picker lists non-postable parent accounts (unlike cash-payment's leaf-only). Posting to a parent is rejected, but save()'s error handler shows no toast — zero feedback to the user.

How to run

# from the repo
cd e2e
npm install && npm run install:browsers   # first time

npm run test:smoke     # all 133 routes — green baseline
npm test               # everything (read-only; writes auto-skip)
npm run test:ui        # interactive explorer
npm run report         # open the Playwright HTML report
Write flows. 62 create / edit / post / delete scenarios are gated behind ALLOW_WRITES=true — enable only against a test tenant. This run had them on; accounting alone created 7 records.
