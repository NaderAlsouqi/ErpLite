تصميم مقترح للنظامA proposed design for the system

تطوير للهوية الحالية وليس استبدالاً لها — نحتفظ بالكحلي والأحمر، ونعيد ترتيب المعلومات وتوزيع الألوان بحيث تُقرأ الشاشة أسرع ويقلّ الضغط الذهني على المستخدم. An evolution of the current identity, not a replacement — the navy and red stay; what changes is how information is ordered and how colour is assigned, so screens read faster with less cognitive load.

٤ · ما الذي تغيّر ولماذا4 · What changed, and why

شريط مستند ثابتA fixed document band

مسار التنقّل والعنوان ورقم المستند والحالة والأزرار — كلّها في صفّ واحد وبنفس الموضع في كل الشاشات. لا يعود المستخدم يبحث عن زر الحفظ من صفحة لأخرى. Breadcrumb, title, document number, status and actions live in one row, in the same place on every screen. Users stop hunting for the save button from page to page.

أزرار متنقّلةموضع واحد ثابت

الأحمر لم يعد يعني «أنت هنا»Red no longer means "you are here"

تمييز الصفحة المفتوحة صار بلون فيروزي هادئ مع شريط جانبي، والأحمر بقي للهوية والحذف. هذا وحده يخفّض «الضجيج البصري» في القائمة الجانبية بشكل ملحوظ. The active page is marked with a calm teal and an edge bar; red is reserved for brand and delete. This alone measurably lowers visual noise in the sidebar.

أحمر = نشطفيروزي = نشط

المبالغ والقيد دائماً ظاهرانMoney and the entry stay visible

عمود جانبي ملتصق يعرض المبالغ والقيد المحاسبي أثناء الإدخال — يرى المحاسب أثر ما يكتبه قبل الحفظ، بدل النزول والصعود في الصفحة. A sticky rail keeps totals and the journal entry in view while typing — the accountant sees the effect of the entry before saving, instead of scrolling up and down.

تمرير للأسفلعمود ملتصق

الحالة كنظام موحّدStatus as one system

مؤشّر مراحل + شارة واحدة بنفس المفردات والألوان في كل المستندات (مسودة، بانتظار، معتمد، مرحّل، ملغى) — يتعلّمها المستخدم مرة واحدة. One stepper plus one badge, with the same vocabulary and colours across every document (draft, pending, approved, posted, cancelled) — learned once, applied everywhere.

شارات مختلفة لكل صفحةمفردات موحّدة

كثافة أعلى بمساحة أقلMore density, less dead space

تصغير الحشو وتوحيد ارتفاع الحقول أظهر ضعف عدد الصفوف في الشاشة نفسها — نظام ERP يُدار بالكيبورد ويحتاج معلومات لا فراغات. Tighter padding and a single field height roughly double the rows visible on the same screen — an ERP is driven by keyboard and needs information, not whitespace.

حقول متباعدةشبكة مضغوطة

جداول تُقرأ بالعينTables you can read at a glance

رأس ثابت عند التمرير، تظليل متناوب للصفوف، أرقام محاذاة لليسار بخط ثابت العرض، وصف إجمالي أسفل الجدول، وأزرار الصف تظهر عند المرور. Sticky header, zebra rows, end-aligned tabular figures, a totals row, and row actions that appear on hover.
